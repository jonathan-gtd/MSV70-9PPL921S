Quote:
Originally Posted by CobraMarty
My speedo is off by 5mph. At speedo indicated 80 mph, it is only doing 75 GPS mph.

Is there any code in the ECU programming for the speedo like 'revolutions/mile' or 'pulses/mile' of the speed sensor.
IIRC the 'speed sensor' is the tone rings for the ABS. IDK which one or if it's an average of all 4.

For a 26" tire, there are about 775 tire rotations/mile.
I am off about 6% and if I can change the code number by 6% less, I could correct my speedo reading.
You will need to code it in KOMBI

Do this:
Enable digital speedometer:
Digital speedometer
• active
• not active
The current speed is shown in the digital display below the speedometer. (codable in KOMBI)

Disable correction
Digital speedometer correction
• true speed
• ‘corrected’ speed
Per default the speed shown in the digital speedometer is ‘corrected’ by the car. This has the effect that the shown speed is a bit higher than the true speed of the car. (codable in KOMBI)

Don't bother with correction with analog speedometer as it does not work with US model cars. At least this way you will have true speed (corresponding to GPS) indicated on your dashboard (in digital format).
