Regarding disa positions, if I remember right, 100 means both flaps closed. 50 means one flap open, the other flap closed, and 0 means both flaps opened. I think the big flap would never be open without the small flap being opened, but I'm not sure.

yep: Deak Schwelle DISA (K_DISAIST_B1) which is "disable threshold DISA" is set to 99.998

Obererschwelle DISA (K_DISAIST_B2) which is "upper threshold DISA" is set to 50

Unterschwelle DISA (K_DISAIST_B3) which is "lower threshold DISA" is set to 0.

now, as far as what do upper and lower thresholds mean, I have no idea..

the upper threshold RPM hysteresis is set from 3270-4270rpm, so I'm pretty sure that's flap 1.

and I was wrong, flap 1 can be closed while flap 2 is opened. that one is set at 25%..

I'll do it the same way I do it by hand.

1st: search for the string directly. If that fails:
2nd: search for the string with slightly different value ranges, or:
3rd: search for nearby strings that should match, and iterate until you find the right set

single bytes are hardest, especially switches that are just 1's and 0's. Sometimes I iterate my search for groups of 4-8 bytes nearby, and then have to count my way over to where I think it is.

I'll have to build a bit of a statistical model to define how close of a match I think it is. It will be some work, but I have a good idea of how to do it since I've done it a lot myself. It's just a matter of capturing that into a few lines of code..
