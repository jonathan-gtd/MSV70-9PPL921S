Can anyone review these instructions on flashing the 330i GM transmission file using WinKFP? I took the instructions from an Alpina transmission flash thread and found the 330i ZB number somewhere here.

Code:
1. Open WinKFP
2. Press (F1) comfort mode
3. Press (F2) Choose ZUSB
4. Choose ECU GM1912
5. Find ZB 7587776
6. Click OK
7. Press (F4) 
8. Enter my VIN 
9. Click OK
10. Press DONE (F8)
11. Press (F3) Program

Pop up window will say you can code the ECU X more times - click OK

Flashing begins. Wait until it reaches 100% twice. The first bar will finish rather quickly and then another bar progress of 100% will take about 3-4 minutes.

If successful, pop up screen saying programming done - click OK

Shut off car by taking key out. 
Lock car with key, wait 5 minutes.
Start the car. Should not have any warning lights or CEL.
