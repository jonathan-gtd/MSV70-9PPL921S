# Lexique des fragments FSW

Les mots-cles FSW de BMW sont construits par assemblage de fragments allemands separes par des `_`. Ce lexique est la cle de lecture utilisee pour traduire automatiquement les catalogues par module.

**499 fragments traduits**, **40 fragments ambigus ou non identifies**.

---

## Comment lire un FSW

```
SPIEGEL_KOMFORT_EINKLAPP
   |        |         |
   |        |         +-- EINKLAPP  = rabattement
   |        +------------ KOMFORT   = confort
   +--------------------- SPIEGEL   = retroviseur
```

> retroviseur - confort - rabattement = **rabattement des retroviseurs par la telecommande**

Le sens global se reconstruit en lisant les fragments de gauche a droite. La traduction automatique des catalogues ne fait rien de plus que cela : elle ne devine pas la fonction, elle en donne les composants.

## Limite honnete de la methode

Cette traduction est **morphologique**, pas semantique. Elle decompose le nom, elle n'explique pas l'effet reel de la fonction sur le vehicule.

`TUERAUF_STOP_MAUT` se traduit en *porte ouverte - arret - peage*. Il faut connaitre la fonction peage de BMW (remontee de vitre d'une impulsion) pour comprendre que ce code interrompt cette fonction quand une portiere est ouverte.

**La traduction oriente la recherche. NCS Dummy et l'essai sur le vehicule tranchent.**
