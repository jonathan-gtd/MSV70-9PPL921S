# Lexique des fragments FSW

Cle de lecture des catalogues. Les mots-cles BMW sont des assemblages de fragments
allemands separes par `_`.

**1294 fragments traduits** · **130 lectures probables** (marquees `(?)`)

Couverture : **100 % des 1 738 fonctions** du perimetre vehicule.

---

## Comment lire un FSW

```
SPIEGEL_KOMFORT_EINKLAPP
   |        |         |
   |        |         +-- EINKLAPP = rabattement
   |        +------------ KOMFORT   = confort
   +--------------------- SPIEGEL   = retroviseur
```

> retroviseur - confort - rabattement = **rabattement des retroviseurs par la telecommande**

---

## Les niveaux de certitude

| Rendu | Signification |
|---|---|
| `retroviseur` | Traduction etablie |
| `securite (?)` | Abreviation BMW non documentee — lecture la plus probable |
| `[identifiant BMW C750A]` | Identifiant interne, pas un mot |
| `[variante C03]` | Index de variante de codage |

Le `(?)` signale une deduction, pas une source.
