# Lexique des fragments FSW

Les mots-cles FSW de BMW sont construits par assemblage de fragments allemands separes par `_`.
Ce lexique est la cle de lecture des catalogues.

**787 fragments traduits** · **40 ambigus ou non identifies**

Les occurrences comptent uniquement le perimetre du vehicule (1 779 fonctions).

---

## Comment lire un FSW

```
SPIEGEL_KOMFORT_EINKLAPP
   |        |         |
   |        |         +-- EINKLAPP = rabattement
   |        +------------ KOMFORT   = confort
   +--------------------- SPIEGEL   = retroviseur
```

> retroviseur - confort - rabattement = **rabattement des retroviseurs par la telecommande**

## Ce qui reste non traduit

Environ 760 fragments distincts n'ont pas de traduction etablie, pour 930 occurrences
sur 1 779 fonctions. Ils apparaissent **en gras**.

La plupart sont des sigles internes BMW sans signification publique, et n'apparaissent
qu'une ou deux fois. Les traduire au juge produirait de la fausse certitude.

**58 % des lignes sont entierement traduites.** Sur les 42 % restantes, le fragment
manquant est le plus souvent un suffixe technique, pas le coeur du sens.
