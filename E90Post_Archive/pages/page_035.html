I believe there's a CAN gateway that dumbs it down - I actually use an E60 KGM on my bench setup with my E90 DME, works fine.

It's sort of moot since you only have to change the one byte to get around it, but it was a short, concise sub routine that looked like a good place to start. There are over 800 main functions and god knows how many sub functions so getting a complete disassembly would take eons.. gotta start somewhere!

oh, the VSS limitation selection is also chosen via CAN. You can alter the one that your car defaults to, but you can't change which of the 4 to use. It's still maxed out at FF or 255kph.

I also learned that the vehicle config is set via CAN - I reset mine on the bench and it all went blank. I did it in my car, and they came back as soon as I restarted the car. I think it is saved inside the DME (otherwise the bench would always show nothing), but the only way to change an option is to have it connected to the CAN bus to the other DMEs. So now that I've added the sport switch to my VO, if I turn it on in the DME, and reset the config again, I think that will work..

So in NCS Expert, what does the MSV70.C## module actually refer to? That sure made it seem like the speed governor and powerclass can be altered through NCS so long as the DME is virginal

As far as I can tell, there's no real CAN-gateway on the E83/E85 cars. There is an "Integrated Supply Module (IVM)" on those cars that may isolate the EGS and DSC from the rest of the CAN-bus, but the DME sits on the same wires as the instrument cluster and steering angle sensor which definitely use the old CAN format. That IVM might supply a separate message to set that powerclass by itself though. But that seems to have the same part number on all E83/E85 MSV70 variants and doesn't appear to be a codeable module, so I don't think that sets it.
