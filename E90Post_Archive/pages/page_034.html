Gini, need beta testers? I can bench flash, no worries about bricking a car.

Poking around in the disassembly learning stuff. Found everything related to the power class byte including the RAM addresses - it looks to me like the vehicle power class is actually stored on a different module, perhaps in the VO. The DME requests the VPC via CAN and compares that to the value stored in c_state_pow_clas_veh. Naturally if it doesn't match it throws an error code and the car can't start.

So I think that means aside from hacking the DME, it might be possible to change the VPC using the VO or another module. Of course, it's easy enough to just change the VPC to match your car.
