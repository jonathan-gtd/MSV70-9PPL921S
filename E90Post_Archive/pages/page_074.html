I had 330i msv70 before and now 125i e88, so I'm interested in tuning msv ecus.
I've been trying to find what are the differences in software between 25i and 30i, and I stumbled upon software version 9QKMG7 files for both versions.
I will put them in attachment. Main difference is in software between addresses 40000-6129E, and difference is only in about 47 maps. Since I don't have damos or xdf for msv80, I've not been able to understand meaning lot of those maps.

But I think I found address for power class 41C7A (8-bit) as this byte is 2 in 130 and 0 in 125 software.

I've been comparing values from msv70 xdf here and found some maps in msv80, but need to spend a lot more time..
Also area after 49406 looks like rev limiters.
area around 514EA dtc codes
5AED2 20x20 - valve lift map
6091E 16X20 - ignition angle
5CD6C KL_MDMAX
5B206 8x1 - max cam lift
..ect

but what I'm looking for which map is responsible for activating 3-stage disa ?


Also I already have pro tuned files for 125i & 130i , but really to compare it I need to define maps first. On tuned map I see that they have increased lift to 10.0mm, and torqe limiter to 600, ignition angle +1compared to 130i +6 compared to 125i.
Mine car is running one of those, it's big difference from stock but I think it can be improved a lot.

Actually my car softer is 9QKMG1 very similar to version above, so I can easily transfer changes.

Now about reading and writing msv80, I can do that over obd no problem, or in boot mode with x17 no need to hassle with winkfp.

If some of tuners here are interested I can send you tuned files.
