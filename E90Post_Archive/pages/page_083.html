No, the xdf contains information which single map is on which address. There are tools like winols which can help to identify maps, but you have to investigate if this is correct and what each map does.
With some experience, there are some maps which can be identified easily (things like ignition timing, torque limits etc.), but other values are nearly impossible to detect (DTC cutoff flags for example).
The best way is to have a leaked a2l file from the OEM, then you have all the maps with naming and just need to translate a little bit. But these files are rare and often expensive.

You change the powerclass byte in the 330 calibration file to match the powerclass in your car, correct checksums and flash back into your car. You need to unlock the DME so it will not reject the RSA signature, Bimmerlabs has the unlocked program Opa and probably has the 330 calibration file with the modified powerclass available. Easy, don't waste your time trying to change the VO and running hours.

Dreary day outside but a nice day to work on the e91 in the garage today

Set my coding laptop with updated datem, and configured the BMW standard tools to talk to my icom. Hooked up a 50amp charger and got to work.

Pulled the bumper and swapped out the failing xenon bulb on the left side.

Started up ISTA+ to check current codes.

Switched over to winkfp and configured it as described on the bimmerlabs getting started/faq.

Ran the batch to load the RSA Delete Program and the 328i-330i Code onto my DME (used the batch programs supplied by Hassmachine).
Immediately I heard a new intialization sound, I bet that's the DISA valves!

Cleared error codes, though the 4x4 transfer case / no torque sensor error came right back, as did a fuel tank vent error and the 2FA3 no coding error.

Loaded the factory coding into the 6BMOT module, hopefully that will clear the 2FA3 error and won't revert the 330 tune.

Took it for a drive, filled up the gas tank, got some groceries, etc. The transfer case error cleared from the dash as expected after a drive.

The increase is power is occasionally noticable and usually invisible. Drives just like it should.

I realized I didn't clear adaptations, so I'll probably do that tomorrow after work when I check for error codes and reset the xenon bulb timer.

Overall seems to be working well! Yippee!

My experience so far, with only about 25 miles on the 330i code, is that it works well.

It still is not clear what effect the changes to the oil level sensor will mean.
It could be that it will give me a low oil alert when i'm not actually low.
It could be that the gauge will read incorrectly. On mine, it reads in the same position as before the change, but that doesn't mean it will stay accurate through the entire range.
It could initiate limp-home when it isn't actually out of oil.
It could keep right on going *despite being out of oil*.

So, you have to decide for yourself whether you're willing to take those risks, or wait for hassmaschine or others to have time to go through more of the code blocks to find the oil level sensor values to bring the over from the xi.
It was much easier for the MSV70 conversion because there were 325i, 330i, 325xi, and 330xi released around the world, so differences were relatively easy to identify.

330 MSV80 code was only released to a small handful of vehicles.
