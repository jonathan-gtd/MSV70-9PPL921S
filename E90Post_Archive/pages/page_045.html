Is the model number NE53 the 525i, and NE73 the 530i?

that could be your problem. It's not necessary to change anything on the car. The DME has no idea that the tune is from a 530i - that's why we change the power class byte to match the car, instead of the other way around.

That byte is the only thing the DME is looking at, so it's possible changing the model number is now making it fault because now the car doesn't match the DME.

again, the only necessary change for using a 530i/330i file (higher power class) on 525/325i car is the power class byte. Nothing else needs to be changed.

Be sure he keeps the same vehicle code and country code as his original. Those are written into the calibration file and checked.

So just for the record, it would appear the CAN power-class byte is sent from the CAS module and it seems that can be freely set with NCS Expert. And as mentioned above, there are two layers of verification for the BN2000 cars.

First one is the check with what the CAS module. Second one is with a value that's stored in the NVRAM, which the DME only allows to be set if the run time is 0. So since we can't change that value easily, it's easiest to modify the tune and leave the CAS to what it was stock.

Well, it's not the power class byte that controls the power - it's more like a "checksum" that verifies that the tune file you have matches your car (to stop you from changing your 125i to a 130i).

What you need is to flash your car with the file from the 130i - with the one change to the file being you need the power class to match your car.

Here are the power classes I'm aware of:
125i/325i/525i: 00
128i/328i/528i: 01
130i/330i/530i: 02
135i/335i/535i: 03 (need to confirm)

So if you have a 125i and want to use a file from a 130i, you need the power class to be set to 00 in the tune so that the car will not be in limp mode.
