If the power class is the same, it might work with WinKFP (you may get a version string error, but I think you can force that in WinKFP Expert mode).

Power class is actually stored in the car, and then written to the DME over can. However, except for when the DME is brand new, you can't rewrite the power class. There's no way to "virginize" it either, because once the time/mileage counter reaches a certain point, the power class is locked. So instead, you can change it in the tune and flash that, as long as the power class in the tune matches the car.

if the power class is different, then you need to modify it in the binary file you want to flash, and then replace the 0x40000-0x5EB00 section in the external flash with the data from your new tune using BDM. c_state_pow_clas_veh is at 0x44D50 in the 921S program version.
