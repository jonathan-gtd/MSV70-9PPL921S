Benefits are a little more power, more responsiveness, and improved reliability. It's still untested with headers on the E90. On a swap car, we ran into issues because it was missing the ambient temperature sensor, which is used as well as IAT to calculate the air mass.

the IAT should work in any intake that the MAF would. You can actually run the no-MAF tune with the stock MAF in place if you want to see if it works with headers - it just ignores the MAF signal and uses only the built in IAT.
