rjahl & hassmaschine,

I think I've completed the observations on the 325i/330i EGS differences with the 330i tune.

I did well over 200 miles on each SW & paid attention to the main differences. I agreed with the OP from the below thread for the most part.

http://www.e90post.com/forums/showthread.php?t=1011409

330I EGS w/ 325I Tune(tested this before 3 stage swap)- Bit more aggressive in 4-6th gear in "D", 1-3rd seem the same, "DS" more aggressive throughout. If you go WOT, SES light illuminates with "DME: CAN communication" fault

330I EGS w/ 330I tune- Everything seems the same tranny wise as above, except obviously more pull due to the tune, and no SES from communication fault. By far the best setup for "DS" mode daily drivers as its great, but "D" mode just feels stock.

325I EGS w/ 330I tune- Everything is "D" mode is a bit more lively, shifts are smooth & it definitely holds its gear slightly longer during daily driving. "DS" mode isn't as spunky as the 330I EGS but I can deal with that being I don't use DS often except when I'm being an idiot on the expressway.

Figured I'd report back, I know rjahl expressed interest in results...
