Still Guessing
Doing yet more research I'v come up with the following ideas towards the VVL limits

1. I've looked at at another Damos file and found the full label for the VVTLR folder. It's called VVTLR Valtronic Lageregler or "controller". I'm thinking that everything that we are looking for are in this section. The adaption routines look quite complex as they run the cam through various speeds and set points to locate the end stops and develop the 0 and 180 positions on the cam. I'd like to stay away from these.

2. Looking at the Parameters and perhaps "reading tea leaves" I can't help but wonder if we should be looking for a set of "added" values to find the limits. Consider this.

We know the eccentric cam can rest at 0 and 180 degrees in fault conditions
K_DVEXMNAN = 0
K_DVEXMXAN =180.003

Know consider this

K_VVTMAX = 150.010
K_VVTMIN = 19.995
K_VVTSW = 9.998

Total = 180.003 degrees

Coincidence?

Now add
K_VVTMAX = 150.010
K_VVTMIN = 19.995
K_DEXWINKOMA = 2.5

Total =172.51 degrees

This is the value I see in my logs.

This seems to fit the the translation of K_DEXWINKOMA relates to the upper Safe distance, while the K_DEXWINKUMA relates to the lower stop and the value is 3.49. Still close enough to consider correct.

Anyone else have any ideas?

Eccentric cam limits
Curiosity got the best of me.

I pulled the power on the Valvetronic motor and used an Allen key on the motor to run to the eccentric cam to the physical stops. Using INPA on the laptop I recorded the following:

Bottom : 0.4 degrees
Top : 175.3 degrees

I was gentle on the Allen key and stopped when I felt and heard the cam hit the limits.

Not believing the results, I reset the VVL adaptions and tried again. Same numbers.

About 25 turns from top to bottom.

That about sums it, if you want more than 9.7MM valve lift you need to modify something. If there is space on the eccentric cam maybe you can file down the physical stops in the head but who knows what king of tuning nightmare that might cause.


EDIT: I went back to my graphs using the 175.4 degree number and came up with some additional clarifications on the valve lift

172 Degees = 9.72MM
175.4 Degrees = 9.88MM physical limit
178 Degrees - 10.01MM
180 Degrees = 10.1MM

So BMW did not completely lie about the 9.9 MM lift allowable in the Valvtronic II system. You just need to run the eccentric cam against the stops. LOL.
