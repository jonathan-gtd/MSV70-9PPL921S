Yes I mean MSS70. MSS70 & MSV70 are basically the same thing - they were probably developed at the same time, but I'd think MSV70 came first - and BMW needed a newer DME to run the S54 in the Z4M (otherwise, the lift axis maps for valvetronic probably wouldn't be in there).

MSV70 is laid out a lot like the earlier Siemens motorsports DMEs, unlike the earlier ones like MS41, MS43, etc that were a nightmare to decode due to the layout. So it makes sense that MSS70 was ported from it since it's similar anyway.

hey terra, you found my thread.

Good point on the RAM, but the other ones are definitely lengths (the parameter space is dead on ). And it fits within everything else I know about the memory layout. From my earlier attempts at disassembly, I seem to remember a lot of references to the 7F8000+ range. Hrm.

The ISN on these is stored in a separate chip (it can be read on MSV70, and I assume on MSS70, but not MSV80/MSD80). I'm pretty sure it's something akin to the flash counter on MSS54 - it doesn't write those bytes until the flash has completed, as a way to detect whether it had an error half way through or something. Which is really what the MSS54 flash counter is, where if you don't have at least one set of 00 00's at 4800 it won't boot.
