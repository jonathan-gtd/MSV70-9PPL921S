Toujours faire un `git add` + `git commit` + `git push` après chaque modification de fichier dans ce projet.

**Why:** L'utilisateur veut que chaque changement soit immédiatement poussé sur le remote.

**How to apply:** Dès qu'un ou plusieurs fichiers sont modifiés, committer et pusher avant de rendre la main à l'utilisateur.
